## Description longue

### FR

**Macos_GithubProjects** est un hub central pour gérer tous vos projets GitHub locaux : une app macOS en barre de menu, un dashboard HTML interactif et des vues de comparaison local ↔ GitHub. Le scanner analyse le dossier `PROJECTS/` et génère 5 sorties (dashboard, hub portfolio, comparaison, profil GitHub, liste Markdown).

#### ✨ Fonctionnalités clés
- **Menu bar app** — accès rapide à tous les projets depuis la barre de menu, icône par projet et compteur en temps réel
- **Dashboard HTML** — interface web avec recherche instantanée et filtres par groupe et statut Git
- **Comparaison local ↔ GitHub** — matching par remote (gère renommages, typos, casse), dépôts privés inclus via `gh`, dépôts archivés filtrés
- **Hub portfolio** (`hub.html`) — page centralisant tous vos projets, sites et extensions
- **Profil GitHub** — page de profil générée automatiquement
- **Liste Markdown** (`projects.md`) — documentation des projets avec avertissements (no desc, no icon, no git, dirty…)
- **Statut Git visuel** — indicateurs Clean, Dirty, No Remote, No Git
- **Icônes personnalisées** — affichage des `icon.png` de chaque projet
- **Script de parité GitHub** — `check_github_parity.py` vérifie la cohérence local ↔ GitHub via les remotes

### EN

**Macos_GithubProjects** is a central hub for managing all your local GitHub projects: a macOS menu bar app, an interactive HTML dashboard, and local ↔ GitHub comparison views. The scanner analyzes the `PROJECTS/` folder and generates 5 outputs (dashboard, portfolio hub, comparison, GitHub profile, Markdown list).

#### ✨ Key features
- **Menu bar app** — quick access to all projects from the macOS menu bar, per-project icon and live counter
- **HTML dashboard** — web interface with instant search and filters by group and Git status
- **Local ↔ GitHub comparison** — remote-based matching (handles renames, typos, case), private repos included via `gh`, archived repos filtered out
- **Portfolio hub** (`hub.html`) — a page gathering all your projects, sites, and extensions
- **GitHub profile** — automatically generated profile page
- **Markdown list** (`projects.md`) — project documentation with warnings (no desc, no icon, no git, dirty…)
- **Visual Git status** — Clean, Dirty, No Remote, No Git indicators
- **Custom icons** — displays each project's `icon.png`
- **GitHub parity script** — `check_github_parity.py` checks local ↔ GitHub consistency via remotes
